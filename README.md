# Learning FASTapi

Learning fastapi for deployment of AI applications

## Installation process of Module:
- python -m venv venv
- pip install fastapi
- pip install uvicorn


### Using requirements:
- pip install -r requirments.txt


## Run the FASTapi app
"uvicorn main:app --reload"


## Creating endpoint 
we can create HTTP endpoints

- GET: retrive data
- POST: create or send data
- DELETE: remove data
- PUT: update existing data
